## ⚙️ The KAIROS Engine

The KAIROS Engine acts as a **digital prefrontal cortex**, calculating the user's current systemic state through a proprietary math model.

### 1. Neuro-Systemic Decision Tuning (NSDT)

The engine processes a **5-axis vector** `[N, S, D, T, C]` (each 0–100):

| Axis | Name | Description |
|------|------|-------------|
| **N** | Complexity | Structural entropy / dimensional load |
| **S** | Stability | Resistance to state perturbation |
| **D** | Adaptability | Capacity for phase transition |
| **T** | Tension | Opposing-force accumulation |
| **C** | Coherence | Pattern alignment / signal integrity |

From these, the engine derives:

- **Shannon Entropy (H):** Measures uncertainty and noise within the system
- **Decision Pressure:** Weighted calculation of Standard Deviation + Entropy to detect internal conflict (guarded against zero-entropy edge cases)
- **Confidence Score:** Determines stability of the current state classification
- **Unified Field Value:** `U = 0.25·(S/100) + 0.30·(D/100) + 0.20·(T/100) + 0.25·(C/100)`
